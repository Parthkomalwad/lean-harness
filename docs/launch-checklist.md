# Launch checklist

From the old `launch-pack`. Use it before you announce a project.

1. Read the code, README and CHANGELOG. Do not claim a feature you cannot find.
2. Write the positioning in one screen: who it is for, the problem, the fix, one proof.
3. Make sure the README explains the project in ten seconds.
4. Set the repo description and topics.
5. Add a license.
6. Create a release tag with `just release tag`.
7. Test the install command on a clean machine.
8. Check that the demo link works.
9. Write the posts. Put the hook in the first line. Use one link.
